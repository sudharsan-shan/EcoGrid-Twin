# EcoGrid-Twin Documentation Index

This directory contains technical documentation, academic manuscript results, hardware setup specifications, and architectural diagrams for the **EcoGrid-Twin** microgrid monitoring and digital twin platform.

---

## 📑 Documentation Index

1. **[JOURNAL_MANUSCRIPT_RESULTS.md](JOURNAL_MANUSCRIPT_RESULTS.md)**
   - Complete technical results and IEEE/Elsevier journal paper draft.
   - Comprehensive benchmarks for 24-hour microgrid power balance, Thevenin battery dynamics, TNPDCL time-of-use tariff arbitrage, machine learning forecaster metrics, and Physics-Informed Neural Network (PINN) validation.
   - Includes **Limitations** and **Results Traceability** mapping.

2. **[RESULTS_TRACEABILITY.md](RESULTS_TRACEABILITY.md)**
   - Audit trail mapping every table, metric, and figure in the manuscript to the exact script, command, and artifact file that generated it.

3. **[HARDWARE_SETUP.md](HARDWARE_SETUP.md)**
   - Industrial telemetry setup guide for RS485 Modbus RTU/TCP energy meters and MQTT IoT brokers.
   - Register mapping for Schneider EM6400NG / Selec MFM384 meters, SMA Sunny Tripower solar inverters, and Daly BMS.

4. **[DATA_README.md](../dataset/DATA_README.md)**
   - Ground-truth catalog for all CSV datasets distinguishing real observational records (NASA POWER API) from physics-simulated and synthetic campus load profiles.

5. **[Architecture.png](Architecture.png)**
   - System design diagram illustrating physical sensors, edge telemetry ingestion, optimization layer, and digital twin web client.
