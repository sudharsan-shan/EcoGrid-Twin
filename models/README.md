# Models Directory

Trained model artifacts go here:
- `lstm_model.keras` — generated by `backend/ai/lstm/train.py`
- `pinn_model.keras` — generated by `backend/ai/pinn/train.py`
- `scaler.pkl` — generated by `backend/ai/lstm/preprocess.py`

These are not included in the scaffold — run the training scripts to produce them.
