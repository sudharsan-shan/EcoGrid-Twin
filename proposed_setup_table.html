COMPONENT PROPOSED SETUP
Programming language Python 3.13 (backend simulation, AI models, API) & TypeScript / React (digital twin frontend)
Development environment VS Code, FastAPI backend, React + TypeScript + Three.js frontend on a Vite dev server
Dataset Synthetic campus microgrid dataset for 6 facilities (case study: IFET College of Engineering / Chennai Campus)
Dataset size 8,760 hourly intervals (35,040 × 15-min dispatch intervals) across 6 facilities = 52,560 facility-hour records
Input data Simulated facility occupancy and electrical load, Open-Meteo & ERA5 hourly weather, 120 kWp rooftop solar PV, 250 kWh / 60 kW BESS, TNPDCL ToU tariffs
Meta-Twin / AI model Physics-Informed Neural Network (PINN) for battery electro-thermal validation + Stacked LSTM Forecaster (calibrated prediction intervals) + Tariff Dispatch Optimizer
Train / test split First 351 days train, final 14 days test (chronological), seed 42
Evaluation metrics MAE, RMSE, MAPE (Solar: 6.78%, Load: 3.71%), R² (>0.95), Physics Residual Confidence (99.7%)
Scenarios simulated Baseline, heatwave (+3.5 °C HVAC surge), cloud transient dip, examination/event peak surge, Meta-Twin-guided optimal dispatch
